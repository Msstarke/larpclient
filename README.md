# Larp Client

A lightweight Minecraft Fabric mod with overlay rendering and auto-updates.

## Features
- Config GUI (Right Shift or `/larp`)
- Overlay system with draggable positions (F12 or `/larpedit`)
- Cortisol Meter — speedometer-style stress gauge
- Auto-update from GitHub releases

## Download
Grab the latest JAR from [Releases](https://github.com/Msstarke/larpclient/releases).

## Supported Versions
- Minecraft 1.21.10
- Minecraft 1.21.11

## Requirements
- [Fabric Loader](https://fabricmc.net/) 0.16+
- [Fabric API](https://modrinth.com/mod/fabric-api)
- [Fabric Language Kotlin](https://modrinth.com/mod/fabric-language-kotlin)
